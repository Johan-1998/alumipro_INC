# ALUMIPRO — Frontend

Frontend profesional para el sistema interno de ALUMIPRO.

## Stack
- React 19 + TypeScript
- Vite 7
- React Router DOM v7
- CSS puro + CSS Modules
- Notificaciones: react-hot-toast
- Íconos: lucide-react

## Estructura
- `src/app/`: router y composición principal
- `src/components/layout/`: Sidebar, Topbar, AppLayout
- `src/components/ui/`: componentes reutilizables (Button, DataTable, Modal, etc.)
- `src/hooks/`: hooks (useClientes, useProductos, useVentas)
- `src/services/`: consumo de API (`/api/*`)
- `src/pages/`: páginas y flujos
